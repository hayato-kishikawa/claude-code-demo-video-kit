# テイストの決め方

動画の印象（テイスト）は、ひとつの設定ではなく、次の 8 つの軸の組み合わせで決まる。
同じ画面・同じ主張でも、軸を変えると「自治体向けの説明動画」にも「新進気鋭の SaaS のローンチ動画」にもなる。
実例は `examples/meetroom-30s`（落ち着いた版）と `examples/meetroom-30s-saas`（SaaS 版）。画面の HTML と主張は共通で、変えたのはこの 8 軸だけ。

## 着手前に依頼者と決めること

テイストは後から直すと全工程（画像、音、動き）をやり直すことになる。BRIEF.md を書く段階で、次を依頼者に聞いて `taste:` に書く。

1. **見る人と流す場所**：公共・行政向けの説明か、企業向けの営業・展示か、SNS 広告か
2. **近い既存の動画や LP**：「この会社の動画みたいに」と 1 つ挙げてもらうのが一番早い
3. **避けたいもの**：ダークな地、ネオン、課題を並べる構成、人物の顔など（利用者が名指しで嫌うものは必ず聞く）

既定のプリセットから選んでもらい、違うところだけ足すと早い。

## 8 つの軸とプリセット

| 軸 | 落ち着いた説明（calm） | SaaS ローンチ・明るい（saas-bright） | 変える場所 |
|---|---|---|---|
| 地と光 | 薄い灰の地、朝の順光 | 白地にブランド色の淡いグラデーションの光 | `build_frames` の `extra_css`（`.{fid}-ground`）、`index_config.json` の `ground` |
| 被写体 | 後ろ姿の写実写真（静か、落ち着いた色） | 立体の小物（マットな質感、柔らかい影）＋明るいオフィスの写真 | 画像ジョブの `style` 接頭辞（style-prefixes.md） |
| 実画面の見せ方 | 画面いっぱいに置き、ゆっくり寄る | 角丸と影の付いたカードが、傾いた状態から起き上がって浮かぶ | `build_frame` の `punch` ／ プロジェクトの `float_card()` |
| 文字 | 字幕だけ（テロップは作らない） | 冒頭と締めは大きな文字を拍に合わせて出し、そのコマの字幕は外す | `kinetic()` と `index_config.json` の `caption_skip` |
| 動き | Ken Burns（1.0→1.05）、ゆっくり | ばね（`back.out`）、数字のカウントアップ | GSAP の ease、`extra_js` |
| 転換 | ぼかしのクロスフェード 0.5 秒 | 横に押し出す（push）0.35 秒 | `index_config.json` の `transition` と `trans_dur` |
| 音 | 静かなピアノ → 温かいピアノと弦 | 軽いシンセ → 明るいポップなビート（118bpm） | `gen_bgm.py <dir> calm｜upbeat`、`bgm_keys` |
| 声 | 落ち着いた明瞭な調子、デスマス調 | 明るく軽快で歯切れよく、台本を短く（体言止めも可） | `TTS_STYLE`、`ATEMPO`、`lines.json` |

## 軸ごとの注意

- **地と光**：明るい SaaS に寄せたいとき、ダークな地とネオンは「開発者向けツール」の印象が強く、総務や経理向けの業務 SaaS には合わないと言われた。白地に淡い光が無難。
- **被写体**：落ち着いた版の写真の接頭辞（朝の順光、木の家具、後ろ姿）は、自治体や公共の説明動画から引き継いだもの。そのまま流用すると、題材が SaaS でも役所の動画に見える。被写体を「立体の小物」に変えると、一気に製品の広告らしくなる。
- **立体の小物**：gpt-image-2.5 に「soft 3D render、matte clay-like、soft studio lighting、白地にミントと空色の光、左半分は空ける」と書くと、LP の挿絵のような素材がそろう。文字を置く側を空けさせておくと、大きな文字と重ねられる。
- **実画面のカード**：画面いっぱいに置くより小さくなるので、細かい文字は読めない。読ませたいところはカードの中で寄せる（`img` の `scale` と `transformOrigin`）。カードの下端を字幕帯（y 900 以上）にかけない。
- **大きな文字**：字幕と同じ言葉を二重に出さない。大きな文字を出すコマは `caption_skip` で字幕を外す。字幕の SRT には残るので、無音の展示では SRT を使わない。
- **声**：`TTS_STYLE` で「明るく軽快に」と指示しただけで、同じ文でも読みが約 2 割速くなった（c01 の 22 字が 4.2 秒 → 3.4 秒）。話速（`ATEMPO`）を上げる前に、まず声の指示を変える。
- **音**：明るいビートは声とぶつかりやすい。ナレーション中の BGM は 0.24 前後、締めで 0.4 に上げた。
- **転換**：push は 0.35 秒でも目で追える。0.25 秒より短くすると、何が切り替わったか分からない。

## 出す前の確認（テイスト）

1. 8 軸の選択が BRIEF.md の `taste:` と表に書いてある
2. 依頼者が避けたいもの（ダーク、ネオン、顔など）が画面のどこにもない
3. 大きな文字を出したコマで、字幕が重なっていない
4. 実画面のカードが字幕帯にかかっていない
5. BGM が声を消していない（声の区間で −16〜−12 LUFS、BGM だけの区間で上げすぎていない）
