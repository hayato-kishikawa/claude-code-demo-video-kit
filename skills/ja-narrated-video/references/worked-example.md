# 実例：ヘヤマド 30 秒（29.7s・7 コマ）

`examples/meetroom-30s/` の完成形。架空の会議室予約 SaaS の展示会・商談用動画。新しい短尺の動画は、この骨格（場面 → サービス名 → 実画面 3 枚 → 変わった後の場面 → 締め）と時間配分を出発点にする。ビルドは `.hyperframes/build_frames_meetroom.py`。

## 時間割（index_config.json）

コマ尺 = LEAD 0.4 + ナレーション実尺 + TAIL 0.35（最短値あり）。転換は blur crossfade、前のコマを PRE 0.4 だけ延長して重ねる。

## c03 の実画面（ハイライト＋パンチインの手本）

```python
{"img": "ui/app-availability.png", "s": 0, "e": d,
 "hls": [{"box": (506, 124, 180, 72), "at": 0.55, "off": 1.9},     # 時間のチップ
         {"box": (700, 124, 180, 72), "at": 0.85, "off": 1.9}],    # 人数のチップ
 "punch": {"s": 1.4, "tx": 0, "ty": -20, "at": 1.9, "d": 1.3}}     # 中心 (960,560) へ
```
- 座標は 1920×1080 の CSS px。2 倍で撮ったスクショは `[::2, ::2]` に間引いてから白地や枠色の連続区間を数えると、パネルの箱が出る。
- 最初は中心 (760,520) に寄せて左端にサイドバーの文字が半分見切れた。端の条件 `960 - S*cx < 0` だけでなく、**画角に入る範囲（cx ± 960/S）に余計なものがないか**も見る。

## 注記ピルの位置

既定は右上だが、実画面は右上にボタンやユーザー名がある。`extra_css` で左下（字幕帯の外）に移した。
```python
def note_css(fid):
    return f".{fid}-note{{top:auto;right:auto;left:40px;bottom:24px;font-size:18px;}}"
```

## 締めのコマ（画像なし・extra_html だけ）

`build_frame(fid, d, [], extra_css=…, extra_html=…, extra_js=…)`。ロゴは HTML で組み、灯る窓だけ `backgroundColor` を tween する。
